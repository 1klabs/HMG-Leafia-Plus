HMG Leafia Plus fingerprint kit (read-only)

1. Copy everything in this folder (NEMESIS.data, NEMESIS.sh, lpatch,
   recipes/) to the root of an exFAT or FAT32 USB drive.
2. Car on, plug the drive in, tap Yes when NEMESIS asks to run it.
3. Wait for the success message, then unplug.
4. Open the compatibility page and drop LEAFIA-REPORT.txt on it.

Nothing on the car is changed. The report has no personal data and no
Kia/Hyundai code, so it is safe to share publicly.
